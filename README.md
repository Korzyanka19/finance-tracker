
# 💰 Finance Tracker — Умный менеджер личных финансов

Современное одностраничное приложение (SPA) для контроля личных финансов. Проект сочетает в себе высокую производительность, строгую типизацию и интерактивную визуализацию данных.

## 🚀 Основные возможности

- 📊 Интерактивная аналитика: Визуализация расходов по категориям с помощью динамического графика-пончика (Donut Chart) на базе библиотеки Recharts. Реализована логика группировки мелких трат в категорию «Другое».
- ⚙️ Полный цикл CRUD: Добавление, редактирование, удаление и просмотр транзакций в реальном времени.
- 🔍 Продвинутый поиск и фильтрация: 
  - Живой поиск по названию и категории.
  - Фильтрация по типу операции (Доход / Расход).
  - Сортировка по дате и сумме (по возрастанию и убыванию).
- 💾 Персистентность данных: Использование кастомного хука useLocalStorage для сохранения состояния между сессиями браузера.
- 📥 Экспорт в CSV: Возможность выгрузки всей истории транзакций в формат таблицы для дальнейшего анализа.
- 💎 Smart UI/UX:
  - Адаптивный дизайн (Mobile First) на Tailwind CSS.
  - "Умное" форматирование чисел (сокращение больших сумм: 15 000 -> 15тыс).
  - Групповое управление (разворачивание/сворачивание всех деталей транзакций одним кликом).

 🛠 Стек технологий

- Core: React 18 + Vite
- Language: TypeScript (интерфейсы для всех типов данных)
- Styling: Tailwind CSS
- Charts: Recharts
- Icons: Lucide React
- Hooks: Custom Hooks (LocalStorage), UseMemo для оптимизации вычислений.

 📁 Архитектура проекта

Проект организован по модульному принципу:
- src/components — функциональные React-компоненты.
- src/hooks — кастомные хуки для логики хранения.
- src/utils — чистые функции (хелперы для форматирования, сортировки и экспорта).
- public — статические ресурсы и документация.

 📦 Установка и запуск

1. Клонируйте репозиторий:
   
   git clone https://github.com/ВАШ_ЛОГИН/finance-tracker.git
   
2. Установите зависимости:
   
   npm install
   
3. Запустите проект в режиме разработки:
   
   npm run dev
   
4. Для создания продакшн-сборки:
   
   npm run build
